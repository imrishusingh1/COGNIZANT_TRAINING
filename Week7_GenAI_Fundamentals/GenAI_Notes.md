# Generative AI Fundamentals

## What is Generative AI?
Generative AI refers to deep-learning models that can take raw data—say, all of Wikipedia or the collected works of Rembrandt—and "learn" to generate statistically probable outputs when prompted. At a high level, generative models encode a simplified representation of their training data and draw from it to create a new work that's similar, but not identical, to the original data.

## Key Technologies
- **Large Language Models (LLMs):** Models like GPT-4, Gemini, and Claude that are trained on vast amounts of text data to understand and generate human-like text.
- **Diffusion Models:** Used primarily for image generation (e.g., Midjourney, Stable Diffusion, DALL-E) by adding noise to an image and then learning to reverse the process to generate new images from text prompts.
- **Transformers:** The underlying architecture (introduced by Google in 2017) that powers most modern GenAI models, enabling them to process sequential data and understand context over long distances in text.

## Prompt Engineering
The practice of designing and refining inputs (prompts) to get the optimal desired output from a generative AI model.
- **Zero-shot prompting:** Asking the model to perform a task without giving it any examples.
- **Few-shot prompting:** Providing the model with a few examples to guide its output format and style.
- **Chain-of-thought prompting:** Asking the model to "think step-by-step" to improve reasoning and accuracy on complex tasks.

## Applications in Software Engineering
- Code Generation (GitHub Copilot, Gemini Code Assist)
- Automated Unit Testing
- Code Refactoring and Explanation
- Bug Detection and Fixing
